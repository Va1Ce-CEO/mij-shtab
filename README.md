# Мій штаб

Особистий планувальник: робочі зміни, пари з університету, справи з дедлайнами,
спорт із планом підготовки, покупки, підписки та щоденні звички.

Це один статичний сайт без збірки: HTML, CSS і JavaScript в одному файлі.

## Як запустити локально

Service worker працює лише через http(s), тому просто відкрити файл замало:

```
python3 -m http.server 8000
```

Далі відкрий http://localhost:8000

## Як опублікувати

Підійде будь-який статичний хостинг із HTTPS:

- **GitHub Pages** — Settings → Pages → Deploy from branch → main / root
- **Netlify** — перетягнути цю теку на netlify.com/drop
- **Cloudflare Pages** — Create project → Upload assets

## Як поставити на iPhone

1. Відкрити адресу сайту в Safari
2. «Поділитися» → «На початковий екран»
3. Застосунок відкривається з власною іконкою, без адресного рядка, і працює офлайн

## Дані

Зараз дані лежать у localStorage того пристрою, де ти працюєш.
У налаштуваннях є «Копія всіх даних» і «Відновити з копії» — через них
дані переносяться між пристроями вручну.

Автоматична синхронізація вмикається через `remote` у коді: об'єкт із методом
`put(state)`, що повертає Promise. Поки `remote` дорівнює null, застосунок
працює лише з цим пристроєм.

## Файли

- `index.html` — увесь застосунок
- `sw.js` — офлайн-кеш
- `manifest.webmanifest` — назва, іконки, режим standalone
- `icon-*.png`, `apple-touch-icon.png` — іконки
